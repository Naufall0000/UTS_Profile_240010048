PERTEMUAN 1

Jenis Layanan dalam Cloud Computing

Pada pertemuan pertama, tugas yang diberikan adalah mencari dan menjelaskan layanan apa saja yang tersedia dalam cloud computing. Secara umum, layanan cloud dapat dikelompokkan menjadi tiga jenis utama, yaitu Infrastructure as a Service (IaaS), Platform as a Service (PaaS), dan Software as a Service (SaaS).

1. Infrastructure as a Service (IaaS)

IaaS adalah layanan cloud yang menyediakan infrastruktur komputasi dasar melalui internet. Infrastruktur tersebut dapat berupa server virtual, jaringan, dan ruang penyimpanan data.

Dengan IaaS, pengguna bisa menyewa server tanpa harus membeli komputer server fisik sendiri. Pengguna juga memiliki kendali untuk mengatur sistem operasi, konfigurasi jaringan, dan aplikasi yang akan dijalankan. Sementara perangkat fisiknya tetap dikelola oleh penyedia layanan cloud.

Contoh layanan IaaS:
  • Amazon EC2: Menyediakan server virtual yang dapat digunakan untuk menjalankan website dan aplikasi.
  • Google Compute Engine: Menyediakan mesin virtual yang berjalan di infrastruktur Google Cloud.
  • Microsoft Azure Virtual Machines: Menyediakan komputer virtual dengan pilihan sistem operasi dan spesifikasi tertentu.
  • DigitalOcean Droplets: Menyediakan server virtual yang dapat digunakan untuk hosting website dan aplikasi.

2. Platform as a Service (PaaS)

PaaS merupakan layanan cloud yang menyediakan platform siap pakai untuk mengembangkan, menguji, dan menjalankan aplikasi. Pengguna tidak perlu repot mengurus seluruh kebutuhan server dan sistem operasi karena sebagian besar pengelolaannya sudah ditangani penyedia layanan.

Contohnya, seorang programmer ingin membuat aplikasi berbasis web. Dengan PaaS, programmer dapat lebih fokus menulis kode dan mengembangkan fitur aplikasi tanpa harus mengatur server dari awal.

Contoh layanan PaaS:
  • Google App Engine: Platform untuk menjalankan aplikasi tanpa mengelola server secara langsung.
  • Heroku: Platform untuk melakukan deployment aplikasi web.
  • Azure App Service: Layanan untuk membangun dan menjalankan aplikasi web di Microsoft Azure.
  • Vercel: Platform deployment yang banyak digunakan untuk website dan aplikasi frontend.

3. Software as a Service (SaaS)

SaaS adalah layanan berupa aplikasi atau perangkat lunak yang sudah siap digunakan melalui internet. Pengguna tidak perlu menginstal dan mengelola server aplikasi sendiri karena penyedia layanan bertanggung jawab terhadap infrastruktur dan pemeliharaan sistemnya.

Contohnya, ketika kita menggunakan Gmail, Google Drive, atau Microsoft 365, kita hanya perlu masuk ke akun dan menggunakan fitur yang tersedia. Kita tidak perlu mengurus server tempat aplikasi tersebut berjalan.

Contoh layanan SaaS:
  • Google Workspace: Gmail, Google Docs, dan Google Drive.
  • Microsoft 365: Word, Excel, PowerPoint, dan layanan kolaborasi.
  • Canva: Aplikasi desain grafis berbasis web.
  • Zoom: Aplikasi untuk pertemuan dan komunikasi online.
  • Moka POS: Aplikasi kasir digital berbasis cloud untuk membantu bisnis mengelola transaksi penjualan.

Perbedaan IaaS, PaaS, dan SaaS

Jenis Fungsi Utama Contoh
IaaS Menyediakan infrastruktur seperti server, jaringan, dan penyimpanan. AWS EC2, Google Compute Engine.
PaaS Menyediakan platform untuk mengembangkan dan menjalankan aplikasi. Heroku, Google App Engine.
SaaS Menyediakan aplikasi siap pakai melalui internet. Gmail, Canva, Moka POS.
Kesimpulan: Ketiga jenis layanan tersebut memiliki fungsi yang berbeda. IaaS lebih berfokus pada penyediaan infrastruktur, PaaS menyediakan platform untuk pengembangan aplikasi, sedangkan SaaS menyediakan aplikasi yang langsung dapat digunakan oleh pengguna.

PERTEMUAN 2

Kelemahan Menggunakan Layanan Cloud

Pada pertemuan kedua, tugas yang diberikan adalah menjelaskan kelemahan ketika menggunakan layanan cloud, khususnya saat kita menyewa atau menggunakan aplikasi yang disediakan oleh pihak lain.

Cloud memang memberikan kemudahan karena pengguna tidak perlu membangun seluruh infrastruktur sendiri. Namun, ada beberapa kekurangan yang perlu diperhatikan.

1. Ketergantungan pada Koneksi Internet

Salah satu kelemahan utama layanan cloud adalah ketergantungan terhadap internet. Karena aplikasi dan data diakses melalui jaringan, pengguna membutuhkan koneksi internet yang stabil.

Jika koneksi internet terputus atau mengalami gangguan, aplikasi bisa menjadi lambat atau tidak dapat diakses. Hal ini dapat mengganggu pekerjaan yang sedang dilakukan.

Contoh pada usaha kuliner:

Sebuah restoran menggunakan aplikasi kasir berbasis cloud seperti Moka POS. Ketika koneksi internet di restoran mengalami gangguan, beberapa fitur yang membutuhkan koneksi internet dapat terganggu. Akibatnya, proses transaksi dan pengelolaan data bisa menjadi kurang lancar, tergantung fitur dan dukungan offline dari aplikasinya.

2. Keamanan dan Privasi Data Berada pada Pihak Ketiga

Ketika menggunakan aplikasi cloud, sebagian atau seluruh data biasanya disimpan pada infrastruktur milik penyedia layanan. Artinya, pengguna mempercayakan penyimpanan dan pengelolaan data kepada pihak ketiga.

Kondisi ini dapat menimbulkan risiko jika penyedia layanan mengalami kebocoran data, serangan siber, atau gangguan keamanan. Data penting milik pengguna atau perusahaan berpotensi disalahgunakan apabila perlindungannya tidak memadai.

Contoh pada aplikasi kasir:

Aplikasi kasir dapat menyimpan informasi transaksi, data produk, laporan penjualan, dan informasi bisnis lainnya. Jika sistem penyedia mengalami kebocoran data, informasi bisnis tersebut berpotensi terekspos kepada pihak yang tidak berwenang.

3. Ketergantungan kepada Penyedia Layanan

Pengguna cloud juga bergantung pada kebijakan dan keberlangsungan penyedia layanan. Jika penyedia mengubah harga berlangganan, menghentikan fitur, atau mengalami gangguan, pengguna harus menyesuaikan diri dengan perubahan tersebut.

4. Biaya Berlangganan yang Terus Berjalan

Beberapa aplikasi cloud menggunakan sistem pembayaran bulanan atau tahunan. Walaupun pengguna tidak perlu membeli server sendiri, biaya langganan tetap harus dibayarkan selama layanan digunakan.

Kesimpulan: Layanan cloud memiliki beberapa kelemahan, seperti ketergantungan internet, risiko keamanan data, ketergantungan pada penyedia layanan, dan biaya berlangganan. Oleh karena itu, sebelum memilih layanan cloud, pengguna perlu mempertimbangkan kebutuhan dan risikonya.

PERTEMUAN 3

Keuntungan dan Kekurangan SaaS

Pada pertemuan ketiga, pembahasan berfokus pada Software as a Service atau SaaS. Tugasnya adalah menjelaskan keuntungan dan kekurangan ketika menggunakan SaaS untuk aplikasi tertentu.

Salah satu contoh yang dekat dengan kehidupan sehari-hari adalah aplikasi kasir digital seperti Moka POS. Aplikasi ini digunakan oleh bisnis, termasuk restoran, kafe, dan usaha makanan untuk membantu proses penjualan dan pengelolaan bisnis.

Moka POS

Moka POS merupakan aplikasi Point of Sale atau sistem kasir digital. Aplikasi ini membantu pemilik usaha dalam mencatat transaksi penjualan dan mengelola kegiatan operasional bisnis.

Karena berbasis layanan digital, pemilik usaha dapat menggunakan sistem tersebut tanpa harus membangun aplikasi kasir sendiri dari awal. Data dan pengelolaan bisnis dapat diakses melalui perangkat yang didukung oleh layanan.

Cara Moka POS Menggunakan Cloud?

Misalnya, sebuah restoran menggunakan Moka POS untuk melayani pelanggan. Ketika kasir memasukkan pesanan dan menyelesaikan transaksi, informasi penjualan dapat tercatat dalam sistem. Pemilik usaha kemudian dapat melihat laporan penjualan melalui dashboard yang disediakan.

Dengan sistem berbasis cloud, pemilik usaha tidak harus berada di depan mesin kasir untuk memantau seluruh aktivitas bisnis. Selama memiliki akses dan izin yang sesuai, informasi dapat dipantau dari perangkat lain.

Contoh penggunaan dalam restoran:
  1. Kasir memasukkan pesanan pelanggan ke aplikasi.
  2. Sistem mencatat transaksi penjualan.
  3. Data transaksi tersimpan dan dikelola oleh sistem.
  4. Pemilik usaha dapat melihat laporan penjualan.
  5. Data tersebut dapat membantu pemilik mengevaluasi perkembangan bisnis.

Keuntungan Menggunakan SaaS seperti Moka POS

  • Mudah digunakan: Pengguna dapat langsung memakai aplikasi tanpa harus membuat sistem kasir sendiri.
  • Menghemat biaya awal: Pemilik usaha tidak harus membangun infrastruktur server dan mengembangkan aplikasi kasir dari awal.
  • Pengelolaan lebih praktis: Transaksi dan laporan penjualan dapat dikelola melalui sistem digital.
  • Akses lebih fleksibel: Pemilik usaha dapat memantau informasi bisnis dari perangkat yang didukung selama memiliki koneksi dan hak akses.
  • Pembaruan sistem: Pembaruan aplikasi dan pemeliharaan layanan umumnya ditangani penyedia.

Kekurangan Menggunakan SaaS seperti Moka POS

  • Bergantung pada internet: Gangguan koneksi dapat memengaruhi akses ke fitur yang membutuhkan internet.
  • Biaya berlangganan: Pengguna perlu membayar biaya layanan sesuai paket yang digunakan.
  • Ketergantungan pada penyedia: Pengguna harus mengikuti kebijakan dan ketentuan layanan dari penyedia aplikasi.
  • Risiko keamanan data: Informasi transaksi dan data bisnis perlu dilindungi dengan baik.
  • Keterbatasan penyesuaian: Pengguna tidak selalu bisa mengubah seluruh fitur aplikasi sesuai keinginan karena sistem dikembangkan oleh penyedia.

Ringkasan Keuntungan dan Kekurangan

Keuntungan Kekurangan
Mudah digunakan dan praktis. Membutuhkan koneksi internet untuk fitur online.
Mengurangi kebutuhan membangun server sendiri. Ada biaya berlangganan.
Laporan bisnis lebih mudah dipantau. Bergantung pada penyedia layanan.
Pemeliharaan sistem ditangani penyedia. Pengaturan fitur bisa memiliki batasan.
Kesimpulan: Moka POS merupakan contoh penerapan SaaS dalam dunia bisnis. Penggunaan aplikasi berbasis cloud dapat membantu kegiatan operasional restoran menjadi lebih praktis. Namun, pemilik usaha tetap perlu memperhatikan biaya, koneksi internet, dan keamanan data.

PERTEMUAN 4

Contoh SaaS di Bidang Hotel, Rumah Sakit, dan Kuliner

Pada pertemuan keempat, tugas yang diberikan adalah mencari contoh aplikasi SaaS dalam tiga bidang, yaitu hotel, rumah sakit, dan kuliner. Selain mencari contoh aplikasinya, kita juga perlu memahami kelebihan dan kekurangan penggunaannya.

1. Bidang Hotel dan Reservasi

Dalam bidang perhotelan, SaaS dapat digunakan untuk mengelola pemesanan kamar, data tamu, ketersediaan kamar, pembayaran, dan laporan operasional hotel.

Contoh aplikasi: Cloudbeds

Cloudbeds merupakan platform pengelolaan bisnis perhotelan yang menyediakan fitur untuk membantu pengelolaan reservasi, kamar, dan operasional penginapan. Sistem berbasis cloud membantu pengelola hotel mengakses informasi melalui platform yang disediakan.

Kelebihan:

  • Mempermudah pengelolaan reservasi kamar.
  • Membantu memperbarui informasi ketersediaan kamar.
  • Data operasional dapat dikelola dalam satu sistem.
  • Membantu mengurangi pencatatan manual.

Kekurangan:

  • Membutuhkan koneksi internet untuk akses layanan online.
  • Pengguna perlu membayar biaya sesuai paket layanan.
  • Staf hotel perlu mempelajari penggunaan sistem.
  • Data tamu harus dijaga agar tidak disalahgunakan.

2. Bidang Rumah Sakit

Dalam bidang kesehatan, aplikasi SaaS dapat membantu pengelolaan administrasi rumah sakit, pendaftaran pasien, jadwal pemeriksaan, dan pengelolaan informasi pelayanan.

Contoh aplikasi: Sistem Informasi Manajemen Rumah Sakit (SIMRS) berbasis cloud

SIMRS berbasis cloud merupakan sistem yang digunakan untuk membantu pengelolaan informasi rumah sakit. Contohnya dapat mencakup pendaftaran pasien, jadwal dokter, administrasi, dan informasi pelayanan. Salah satu contoh platform yang dikenal dalam pengelolaan rumah sakit adalah eHospital.

Fitur dan model penyediaan setiap produk dapat berbeda. Tidak semua SIMRS atau eHospital otomatis merupakan SaaS, sehingga perlu diperiksa berdasarkan layanan yang digunakan.

Kelebihan:

  • Membantu mengelola data administrasi pasien.
  • Mempermudah proses pendaftaran dan pengaturan jadwal.
  • Mengurangi pencatatan data secara manual.
  • Informasi dapat dikelola dalam sistem terpusat.

Kekurangan:

  • Data pasien merupakan informasi yang sangat sensitif.
  • Keamanan dan hak akses harus dikelola dengan ketat.
  • Gangguan sistem dapat menghambat pelayanan.
  • Rumah sakit perlu memastikan sistem sesuai kebutuhan dan aturan yang berlaku.

3. Bidang Kuliner dan Restoran

Dalam bidang kuliner, SaaS dapat digunakan untuk mengelola transaksi kasir, menu makanan, stok bahan atau produk, laporan penjualan, dan aktivitas operasional restoran.

Contoh aplikasi: Moka POS

Moka POS merupakan aplikasi kasir digital yang membantu pemilik restoran atau usaha makanan mencatat transaksi, mengelola produk, dan memantau laporan penjualan.

Contohnya, ketika pelanggan membeli makanan, kasir memasukkan pesanan ke aplikasi. Transaksi kemudian dicatat dalam sistem sehingga pemilik usaha dapat memantau hasil penjualan.

Kelebihan:

  • Mempercepat pencatatan transaksi pelanggan.
  • Membantu pemilik usaha memantau penjualan.
  • Mengurangi kesalahan pencatatan manual.
  • Mempermudah pengelolaan produk dan laporan bisnis.

Kekurangan:

  • Beberapa fitur membutuhkan koneksi internet.
  • Pengguna harus membayar biaya berlangganan.
  • Data transaksi dan bisnis perlu dijaga keamanannya.
  • Pengguna bergantung pada ketersediaan layanan penyedia.

Perbandingan Penggunaan SaaS

Bidang Contoh Sistem Fungsi
Hotel Cloudbeds Mengelola reservasi, kamar, dan operasional hotel.
Rumah Sakit SIMRS berbasis cloud Mengelola administrasi, pendaftaran, dan informasi pelayanan.
Kuliner Moka POS Mengelola kasir, transaksi, dan laporan penjualan.
Kesimpulan: SaaS dapat digunakan dalam berbagai bidang pekerjaan. Hotel menggunakannya untuk mengelola reservasi, rumah sakit untuk membantu pengelolaan informasi pelayanan, dan bisnis kuliner untuk mengelola transaksi serta kegiatan kasir. Setiap aplikasi memberikan kemudahan, tetapi tetap memiliki risiko dan keterbatasan.

PERTEMUAN 5

Layanan IaaS untuk Web Server

Pada pertemuan kelima dan keenam, tugas yang diberikan berkaitan dengan pencarian layanan IaaS yang disediakan oleh penyedia cloud melalui internet, khususnya layanan infrastruktur yang berhubungan dengan server web atau hosting.

Sebelum mencari contoh layanannya, kita perlu memahami bahwa web server merupakan sistem yang bertugas menerima permintaan dari browser dan mengirimkan halaman website kepada pengguna.

Dengan menggunakan IaaS, kita dapat menyewa server virtual untuk memasang web server, mengatur sistem operasi, dan menjalankan website sendiri.

1. Amazon EC2 - Amazon Web Services

Website penyedia:

https://aws.amazon.com/ec2/

Amazon EC2 merupakan layanan server virtual dari AWS. Pengguna dapat memilih spesifikasi server seperti jumlah CPU, kapasitas RAM, sistem operasi, dan penyimpanan.

EC2 dapat digunakan untuk memasang web server seperti Apache atau Nginx, kemudian menjalankan website yang ingin dipublikasikan ke internet.

2. Google Compute Engine - Google Cloud

Website penyedia:

https://cloud.google.com/compute

Google Compute Engine adalah layanan infrastruktur yang menyediakan mesin virtual di Google Cloud. Pengguna dapat membuat server virtual dan mengatur sistem operasi serta kebutuhan aplikasi yang akan dijalankan.

Salah satu penggunaannya adalah membuat server untuk menjalankan website, aplikasi web, maupun layanan backend.

3. Microsoft Azure Virtual Machines

Website penyedia:

https://azure.microsoft.com/products/virtual-machines

Azure Virtual Machines merupakan layanan mesin virtual dari Microsoft Azure. Pengguna dapat memilih sistem operasi, kapasitas komputasi, dan konfigurasi server sesuai kebutuhan.

Server tersebut dapat digunakan untuk memasang aplikasi web server dan menghosting website.

Perbandingan Ketiga Layanan

Layanan Penyedia Kegunaan
Amazon EC2 Amazon Web Services Menyediakan server virtual untuk website dan aplikasi.
Compute Engine Google Cloud Menyediakan mesin virtual untuk menjalankan web server.
Azure Virtual Machines Microsoft Azure Menyediakan server virtual dengan konfigurasi sesuai kebutuhan.
Kesimpulan: Amazon EC2, Google Compute Engine, dan Azure Virtual Machines merupakan contoh layanan IaaS. Ketiganya menyediakan server virtual yang dapat dikonfigurasi dan digunakan untuk menjalankan web server maupun aplikasi.

PERTEMUAN 6

Praktik Mengunggah Website ke Hosting Gratis

Pada pertemuan keenam, tugas praktik yang diberikan adalah melakukan registrasi pada layanan web hosting gratis, kemudian mengunggah satu halaman website profil yang sudah dibuat.

Hosting adalah layanan yang menyediakan tempat untuk menyimpan file website agar dapat diakses melalui internet. File website seperti HTML, CSS, JavaScript, dan gambar perlu ditempatkan pada layanan hosting supaya orang lain dapat membuka website melalui alamat yang diberikan.

Contoh Layanan Hosting Gratis

1. GitHub Pages

Layanan hosting gratis dari GitHub yang dapat digunakan untuk menerbitkan website statis berbasis HTML, CSS, dan JavaScript.

Kunjungi GitHub Pages

2. Netlify

Platform yang menyediakan hosting untuk website statis dan mendukung deployment melalui repository Git maupun unggahan file.

Kunjungi Netlify

3. Vercel

Platform deployment untuk website dan aplikasi web. Banyak digunakan untuk proyek frontend dan website statis.

Kunjungi Vercel

Ketiga layanan tersebut dapat digunakan untuk mempublikasikan website profil sederhana. Namun, perlu dipahami bahwa GitHub Pages, Netlify, dan Vercel merupakan platform hosting atau deployment, bukan layanan IaaS seperti Amazon EC2 dan Google Compute Engine.

Langkah Umum Mengunggah Website Profil

  1. Menyiapkan file website. Pastikan file HTML, CSS, JavaScript, dan folder gambar sudah tersusun dengan benar.
  2. Membuat akun hosting. Daftar pada salah satu layanan hosting yang akan digunakan, misalnya Netlify, GitHub Pages, atau Vercel.
  3. Mengunggah atau menghubungkan project. Masukkan file website atau hubungkan repository GitHub sesuai metode deployment yang disediakan platform.
  4. Melakukan proses deployment. Tunggu sampai platform selesai memproses file website dan menerbitkannya.
  5. Mendapatkan alamat website. Setelah berhasil, platform akan memberikan alamat URL yang dapat digunakan untuk membuka website melalui browser.
  6. Melakukan pengecekan. Buka alamat website dan pastikan halaman, gambar, CSS, serta JavaScript tampil dengan benar.

Perbedaan IaaS dan Hosting Website Gratis

Walaupun sama-sama dapat digunakan untuk menjalankan website, IaaS dan platform hosting gratis memiliki perbedaan.

  • IaaS: Pengguna mendapatkan server virtual dan memiliki kendali lebih besar terhadap sistem operasi serta konfigurasi server.
  • Hosting terkelola: Pengguna lebih fokus mengunggah dan menerbitkan website karena pengelolaan server sebagian besar ditangani penyedia.
Kesimpulan: Hosting memungkinkan website dipublikasikan sehingga dapat diakses oleh orang lain melalui internet. Untuk website profil sederhana, layanan seperti GitHub Pages, Netlify, dan Vercel dapat menjadi pilihan yang praktis.

PERTEMUAN 7

Deployment dan Pengelolaan Aplikasi Cloud

Pada pertemuan ketujuh, materi membahas bagaimana aplikasi dijalankan dan dikelola dalam lingkungan cloud. Setelah memahami jenis layanan cloud dan cara mempublikasikan website, kita juga perlu mengenal teknologi yang digunakan untuk menjalankan aplikasi dengan lebih fleksibel.

1. Virtual Machine (VM)

Virtual Machine merupakan komputer virtual yang berjalan di atas perangkat keras fisik. VM memiliki sumber daya seperti CPU, RAM, penyimpanan, dan sistem operasi sendiri.

Dalam cloud computing, pengguna dapat menyewa VM dari penyedia cloud untuk menjalankan website, database, maupun aplikasi lainnya.

2. Container

Container merupakan teknologi untuk mengemas aplikasi beserta kebutuhan pendukungnya agar dapat dijalankan secara konsisten di berbagai lingkungan. Salah satu teknologi container yang banyak digunakan adalah Docker.

3. Kubernetes

Kubernetes merupakan platform untuk mengelola container. Teknologi ini membantu mengatur deployment, jumlah container, dan pengelolaan aplikasi yang berjalan dalam skala besar.

4. Serverless

Serverless merupakan model layanan yang memungkinkan pengembang menjalankan kode atau fungsi tanpa harus mengelola server secara langsung.

Contoh layanan serverless antara lain AWS Lambda, Google Cloud Functions, dan Azure Functions.

5. Scaling dan Load Balancing

  • Scalability: Kemampuan sistem menyesuaikan kapasitas sesuai kebutuhan pengguna.
  • Auto-scaling: Proses menambah atau mengurangi sumber daya secara otomatis berdasarkan kondisi sistem.
  • Load Balancing: Membagi permintaan pengguna ke beberapa server agar beban kerja lebih merata.
  • Cost Optimization: Mengatur penggunaan sumber daya cloud agar biaya tetap efisien.
Contoh penerapan:

Sebuah website toko online mengalami peningkatan jumlah pengunjung ketika ada promosi. Jika hanya menggunakan satu server, server tersebut bisa mengalami beban yang tinggi.

Dengan bantuan load balancing, permintaan pengguna dapat dibagi ke beberapa server. Sementara itu, auto-scaling dapat membantu menambah kapasitas ketika kebutuhan meningkat.

Kesimpulan: Teknologi VM, container, Kubernetes, dan serverless memberikan pilihan untuk menjalankan aplikasi di cloud. Dengan deployment, scaling, dan pengelolaan sumber daya, aplikasi dapat berjalan lebih fleksibel sesuai kebutuhan.
